## 0. 一页结论

### 因果链

v2.2/v2.3 把上轮"风险沟通缺失"的**主干**接上了(风险列+徽标+行染色、风险分组确认+默认取消、动态执行按钮、进度条归位、批量撤销、键盘可达、右键菜单——上轮 X-2/4/5/7/8/9/15/17/22/23/24 共 11 项确认修复无回归)。但复审发现三类残留问题:

```
"修复打折"(声称修了,实际半成品)
  ├─ 勾选保持只恢复"勾",不恢复"取消勾"——recommended 项被静默重新勾上 [L-1, P0]
  ├─ 历史页列头与数据完全错位(时间戳塞 84px 风险列、路径塞 100px 大小列) [L-2, P0]
  ├─ 降级告知追加在 36px 固定高度 info 标签尾部——X-10 修复大概率永远不可见 [L-3]
  ├─ 分类列全英文 + FolderTree 菜单仍"删除文件夹…"(X-13 声称已改未改) [L-8]
  └─ X-16 两处坐标(advancedChk 溢出/列表压状态栏)原样残留 [L-4]

"新功能引入新竞争面"(v2.3 搜索)
  ├─ VolumeIndex 全程无锁:重建索引期间 UI 搜索迭代悬垂指针 → UAF [04-1, P1]
  ├─ SearchPresenter UI 线程无锁写 results_[Search],与执行中 RunPlan 竞争 [04-2, P1]
  ├─ WM_TIMER 无任务态闸 + SetTaskBusy 矩阵漏禁搜索输入框 [04-2b]
  └─ 说明面板 pszMainInstruction 悬垂(模态泵内定时器替换 snapshot_) [04-3]

"状态机新失败模式"
  ├─ WM_APP_TASK_STARTED 无条件锁矩阵:消息序倒置 → 全 UI 永久锁死 [04-4]
  └─ worker 异常被吞不补发 DONE → 同上 [04-5]
```

**另有后端阻塞项(非本次范围但影响搜索全部价值):索引仅 27 项**——两次会话日志一致,31 秒构建仅得 27 项(应为数十万),搜索功能当前实质不可用;UI 会把"索引就绪:27 项"直接展示给用户。
