## 2. 安全与边界(05 为主,03/04 印证)

**最重要发现:门禁的正向链路完整且唯一(SessionService::RunPlan 是所有文件操作的必经之路,grep 证实 UI 不再直接构造 Operation,T-B8),但存在三类缝:**

1. **可绕过(T-B1,Confirmed)**:19 类路径变体对抗测试中,5 类全链路绕过(双分隔符 `C:\\Windows\…`、无盘符 `\Windows\…`、`\\?\` 前缀、UNC、8.3 短名——本机实测 `C:\PROGRA~3\MICROS~1` 指向 ProgramData\Microsoft 9.3GB)。端到端实验:构造规则 → System32 以 Safe/预勾选进列表 → PlanBuilder 通过 → Validate 放行 → QuarantineOp 自检放行 → 移动语法沙箱证实可用(真实系统路径有意未执行,组合证明)。**当前 Json bug 反而挡住了常规恶意文件(只有单行零空白文件可解析)——修 Json 会武装此面,必须先修规范化。**
2. **名单缺口(T-B2,Confirmed)**:C:\Users、C:\Program Files、C:\Program Files (x86)、C:\ProgramData、C:\PerfLogs 全部 Validate=allow——文件夹树右键一次误点+一次确认即可隔离 C:\Users。UI 文案却宣称"系统目录受保护名单拦截"(过度承诺)。另 B-15:隔离区保护只硬编码 C/D/E 盘。
3. **旁路通道(「输入通道×门禁」表,05 §3)**:Undo 完全绕闸(T-B6:history.jsonl 用户可编辑,被改写的 source/target 可让撤销任意移动);Delegate 命令无白名单以管理员执行(T-B4,相对名走 CWD/PATH 可被劫持);$RECYCLE.BIN 特判直通(设计使然);清空隔离区部分失败仍全量标"已释放"(T-B10/03-B7)。

**规则与闸门的自我矛盾(T-B9,Confirmed)**:内置 27 条规则中 6 条(windows-temp/font-cache/wu-download/cbs-logs/dism-logs/minidump)指向 C:\Windows 保护树内——扫描列出、用户勾选、执行被拒,实测全数跳过。这是"扫出来却执行不了"的机制性来源,也直接消耗用户对工具的信任。

**TOCTOU 复验盲区(T-B5,Confirmed)**:FolderTree/AppScanner/去重行不填 lastWriteFiletime → 三通道 mtime 复验静默关闭;反向问题:TEMP 类活跃目录因 mtime 复验被高频误拦("扫描后文件已被修改"),最该清的最容易被拒。

- **风险分析摘要**:确认弹窗升级 TaskDialog——主指令人话("将把 18 项移入隔离区,共 1.46 GB")+按档位分组摘要+后果一句话话术表+"查看将处理的 N 个项目"展开清单+含 Advanced/不可逆项时的验证勾选+**默认按钮=取消**。
- 已证实的关键缺陷:勾选在排序/切 Tab 后全部丢失(X-6);进度条永不可见(X-8);撤销仅单条——18 项需 36+ 击(X-9);确认文案张冠李戴(Apps 讲隔离区,X-7);右键菜单"删除文件夹…"与实际"移入隔离区"术语冲突(X-13);Junk Tab"按时间排序"完全无效(X-14,createTime 未赋值);迁移确认后才提示选目标盘(X-15);无键盘可达(X-12)。

## 4. 稳定性(04 为主)

- **R-1(P0)**:results_ 无锁——执行期间(迁移/DISM 可达分钟级)排序按钮、列头点击、Tab 切换、"打开位置"全部可用且读写同一 vector → 撕裂读/UAF/堆损坏。止血:SetTaskBusy 统一禁用矩阵(0.5h);根治:UI 快照契约(worker 单一写者,UI 经 TakeResults 取走)。

## 5. 后台性能(03 为主)

- **57.4s 垃圾扫描归因**(实测+推算):DirectorySize 尺寸池 ~85%——**WinSxS 302,176 项**(主审已锚定)单线程 DFS 为最重候选,而该规则是 Delegate 策略、尺寸纯展示;**修复索引也省不了它**(USN 记录无 size,ADR-004)。
- **69.2s 大文件扫描**:FastWalk 全 C: ~75% + 去重哈希 ~15%。隔离区(C:\MiniSys.Quarantine,11,540 项/1.4GB)不在排除表——已隔离内容再次出现在大文件页并被推荐可删(B-16)。
- 修复后预期(Likely,需活体校准):跳过 Delegate/InfoOnly 尺寸 + DirectorySize 子树并行 → Junk 10-20s(达标 ≤30s);懒尺寸 → 2-5s 先出列表。
- 其他:MoveJunctionOp 双遍 DirectorySize(B-12);OperationLog 锁外读改写可丢并发 Append(B-8);清空隔离区 O(N²) 重写(B-7);测试进程污染生产日志(B-13)。
